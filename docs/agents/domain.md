# Domain docs

Single context. The glossary is `CONTEXT.md` at the repository root; decisions are numbered ADRs under `docs/adr/`.

**Reading rules.** Read `CONTEXT.md` before naming anything, and use its words exactly — a term with an `_Avoid_` list has one right spelling. Read the ADRs covering an area before proposing a change there, and do not re-litigate a recorded decision without new evidence.

`DESIGN.md` holds the root principles and the module design; it is the acceptance criteria for a change, not a glossary. Research and measurement evidence live under `docs/`.
