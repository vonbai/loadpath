# Issue tracker

Issues for this repository live in **GitHub Issues** at `vonbai/loadpath`, reached with the `gh` CLI.

`to-tickets`, `to-spec`, `triage` and `wayfinder` read from and write to it. Blocking relationships use GitHub's native blocked-by links, so any issue whose blockers are closed can be picked up.

PRs are not a request surface. External pull requests do not enter the triage queue.
